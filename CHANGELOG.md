# Changelog

Changes to the npm packages [gospelo-iconcraft-react](https://www.npmjs.com/package/gospelo-iconcraft-react) and [gospelo-iconcraft-wasm](https://www.npmjs.com/package/gospelo-iconcraft-wasm).
Dates are in JST. Releases before those listed here were not recorded.

## gospelo-iconcraft-react

### 0.6.1 — 2026-11-18

#### Fixed

- **Gradient colors mixing between icons.** Inline SVGs on one page share a single id namespace. Noto Color Emoji uses `SVGID_1_` in every file, so icons were painted with the gradient of whichever icon appeared first. Ids generated by the library (`sticker-shadow` from WASM, `…-bg-grad` and others) could also collide. Every id defined in a rendered SVG now gets a per-component prefix from `useId()`. References are rewritten too: `url(#…)` in attributes, `style` and `<style>`, `href` / `xlink:href`, and `#…` selectors in `<style>`. Applies to `IconCraftView`, `IconCraft` and `IconCraftShape`.
- **`animationTarget: 'shape' | 'icon'` did not animate.**
  - The regexes that add `iconcraft-shape` / `iconcraft-icon-wrapper` never matched, or stopped matching once rotation added a `transform`.
  - `sanitizeSvg` dropped the `<style>` that applies the animation.

#### Added

- Tests: `npm test` (`node --test`, Node 24+).

### 0.6.0 — 2026-11-17

- Depends on `gospelo-iconcraft-wasm` `^0.5.1`, so SVGs exported by Adobe Illustrator (Noto Color Emoji) work through the React components.
- First release of the features developed as "v0.5.0" in this repository after react 0.5.0 was published:
  - Rotation dial overlay on `IconCraftView` (drag to rotate) and 10 dial presets
  - 3 reticle presets, and custom renderers for ring, notch, label and reticle
  - Rotation support in `IconCraftConfig` and `useIconCraft`
  - `WasmManager` cache control
  - `sanitizeSvg`

**Upgrading:** if your project pins `gospelo-iconcraft-wasm` (for example with pnpm `overrides`), raise it to `^0.5.1` as well.

## gospelo-iconcraft-wasm

### 0.5.1 — 2026-11-17

#### Fixed

- **SVGs exported by Adobe Illustrator failed to load** (Noto Color Emoji `2D/svg`, for example). `generate_clippath_with_rotation` cut the SVG at the first `>` in the file, so these inputs broke:
  - an XML declaration or comments before `<svg>`
  - a `DOCTYPE` with internal `ENTITY` declarations
  - `xlink:` or Illustrator `i:` names declared on the root

  Output for SVGs that start with `<svg>` (Twemoji, for example) is unchanged.

#### Changed

- `engines.node` is pinned to `24.22.3`.
